# LFH KI

Cow/wolf/grass game simulation — in a version for terminal and one using pygame.

## Structure

- [`terminal-version/`](./terminal-version/) — original implementation with ASCII output in the terminal (Uebung 1-8)
- [`pygame-version/`](./pygame-version/) — graphical extension using Pygame, incl. smell map for wolf hill-climbing behavior (Ab Uebung 9 hier weiter)

Each subproject has its own `pyproject.toml`, `uv.lock`, and README with setup/run instructions.
To run the projects, navigate into on of the subfolders and their READMEs.
